# Firma Sound — landing page

Site de apresentação da **Firma Sound**, empresa de produção técnica de eventos: sonorização, iluminação cênica, painéis de LED, palcos e estruturas, com montagem, operação e desmontagem.

O objetivo é mostrar o trabalho da empresa e levar o visitante a pedir um orçamento pelo WhatsApp.

**Ver o site:** https://leandromartinstech-code.github.io/firma-sound/

## Destaques

- Abertura cinematográfica controlada pela rolagem
- Vídeos reais de eventos em carrossel
- Layout responsivo para celular, tablet e desktop

Feito com Vite e React.
